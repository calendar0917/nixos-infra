# Pi Web 手动启动

本目录只包含交互式前台启动脚本，不创建 systemd 服务、后台守护进程或自动启动。
Node.js 22 和 `npx` 由现有 Home Manager 配置提供。

## 启动

从仓库根目录执行：

```bash
./deploy/pi-web/start.sh
```

脚本要求交互式终端。首次启动可能需要从 npm 下载包。

## 首次运行

交互式输入并确认登录密码，至少 16 个字符。

密码保存在：

```text
~/.config/pi-web/password
```

目录权限 `0700`，文件权限 `0600`。密码不写入命令行参数，不在终端输出，也不会
进入仓库。脚本拒绝使用符号链接作为密码文件。

## 后续启动

选择：

1. 使用现有密码启动。
2. 重设密码后启动。
3. 退出。

## 访问

```text
http://<局域网IPv4>:30141
http://<Tailscale-IP>:30141
```

Tailscale 客户端需要具有相应访问权限。

局域网 HTTP 访问不具有 HTTPS 保护；通过 Tailscale IP 访问时，网络传输由
Tailscale 隧道加密。

`0.0.0.0` 会监听所有 IPv4 接口。没有公网 IPv4 地址不等于安全隔离；不要为此
配置路由器端口转发或 UPnP。`main` 仅在防火墙开放 TCP 30141，Pi Web 自身的
密码认证保持启用。

## 停止

在运行脚本的终端按 Ctrl+C。关闭前台进程后脚本不会自动重启。

## 版本

`@agegr/pi-web@latest`，每次启动使用 npm 的 latest 分发标签解析版本，允许上游
升级。不能保证每次启动都立即获得新版本，也不保证新版本始终兼容当前 Node.js。

首次启动可能需要从 npm 下载包。
